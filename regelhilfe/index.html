    Regelhilfe

    Einmalige Einrichtung auf diesem Gerät

    Lese-Token eintragen

    Die Spielhilfen liegen im privaten Repository nechromus/RulesHelperData. Für den Zugriff braucht die App einen Token, der nur lesen darf:

    1. Auf GitHub einen neuen Fine-grained token anlegen (Settings → Developer settings → Personal access tokens → Fine-grained tokens).
    2. Repository access: „Only select repositories“ → RulesHelperData.
    3. Permissions → Repository permissions → Contents: „Read-only“. Mehr braucht es nicht.
    4. Ablaufdatum wählen, Token erzeugen, kopieren und hier einfügen.

    Läuft die Regelhilfe schon auf einem anderen Gerät, geht es schneller: dort unter Einstellungen „Token per QR-Code teilen“ wählen und hier „QR-Code scannen“ tippen. Einen geteilten Link kannst du auch einfach in das Feld einfügen.

    Der Token wird nur auf diesem Gerät gespeichert und nur an api.github.com geschickt. Läuft er ab, fragt die App nach einem neuen.

    Geöffnete Spiele werden samt Seitenbildern auf dem Gerät gespeichert und bei neuen Fassungen automatisch aktualisiert. Hier kannst du alle Spiele auf einmal laden, z. B. vor einem Spieleabend ohne WLAN.

    Zugang und Speicher

    QR-Code scannen

    Halte die Kamera auf den QR-Code, den die Regelhilfe auf dem anderen Gerät anzeigt.

    Token teilen

    Auf dem anderen Gerät die Regelhilfe öffnen, beim Einrichten „QR-Code scannen“ tippen und diesen Code scannen.

    Der Code enthält deinen GitHub-Token. Er darf nur lesen, gibt aber Zugriff auf das private Repo. Zeig ihn nur auf deinen eigenen Geräten und nicht in Fotos oder Bildschirmfotos.

    Mit der normalen Kamera-App öffnet der Code die Regelhilfe im Browser (Safari). Eine Regelhilfe auf dem Home-Bildschirm oder in einem anderen Browser hat eigenen Speicher – dort besser in der App scannen.
