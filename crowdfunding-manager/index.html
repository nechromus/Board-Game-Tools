GitHub-Verbindung

Deine Eingaben (Klärungen, Status, Kommentare, Beobachtet, Bilder) werden verschlüsselt im Repository gespeichert und zwischen deinen Geräten abgeglichen. Dafür brauchst du einen fein abgestuften Zugriffstoken: nur dieses Repository, Berechtigung Contents: Read and write. Token und Schlüssel bleiben in diesem Browser.

Schneller: Zugang von einem anderen Gerät übernehmen. Dort unter „Weiteres Gerät koppeln“ einen QR-Code erzeugen und hier scannen.

Oder von Hand verbinden:

Tresor & Passphrasen

Die Daten sind mit einem zufälligen Schlüssel verschlüsselt. Er ist in „Schlüsselplätzen“ gesichert – jede Passphrase öffnet einen Platz. Deine eigene Passphrase legst du hier fest; sie verlässt diesen Browser nicht. Claude bekommt nur die Claude-Passphrase, die du jederzeit ändern oder entfernen kannst.

    Weiteres Gerät koppeln

    Erzeugt einen QR-Code für dein iPhone oder iPad. Damit bekommt das Gerät den Schlüssel und den GitHub-Zugang – ohne Passphrase und Token abzutippen. Der QR-Code allein reicht nicht: Auf dem Gerät gibst du zusätzlich den angezeigten Code ein. Beides gilt 15 Minuten.

    Code für das Gerät:

    Mit der iPhone-Kamera scannen, Link öffnen, Code eingeben. Den QR-Code nicht fotografieren oder weitergeben.

    Datensicherung

    Lädt alles in eine Datei: Projektliste, Pledges, Updates, Mails, deine Eingaben und Bilder. Die Datei lässt sich hier oder mit tools/vault.py import wieder einspielen.
